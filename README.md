# 墨历 · Markdown 简历工作台

一款**本地优先**的 Markdown 简历制作工具：块级所见即所得编辑、A4 纸张实时预览、八套模板一键切换、主题色实时自定义、思源黑体/宋体专业排版、AI 助手（润色 / 优化 / 精简 / 排版 / 提问）与语法检查、智能一页、一键导出 PDF。

**无后端、无账号**：所有数据（简历内容、证件照、AI 配置）仅保存在你自己的浏览器 IndexedDB 中，不上传任何服务器。

## 快速开始

### Windows 一键启动

双击根目录的 **`启动墨历.bat`** 即可：自动定位 Node → 首次运行自动安装依赖 → 启动本地服务 → 打开浏览器。关闭弹出的「墨历服务」命令行窗口即停止服务。

### 命令行方式

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务（http://localhost:5173）
npm run build      # 生产构建（输出 dist/，相对路径可直接静态部署）
npm run preview    # 预览生产构建
npm run typecheck  # TypeScript 类型检查
```

要求 Node.js ≥ 18。

## 功能总览

### 编辑器（Tiptap / ProseMirror 块级编辑）

- **所见即所得**：排版样式与预览模板同步，18+ 种块级元素
- **Markdown 快捷输入**：直接打语法即时转换，无需菜单
  `#`~`######`+空格 → 标题一~六　`- `/`* ` → 无序列表　`1.` → 有序列表
  `>` → 引用　`---` → 分割线　` ``` ` → 代码块
  `**粗**` / `*斜*` / `` `码` `` / `~~删~~` → 加粗 / 斜体 / 行内代码 / 删除线
- **斜杠命令**：输入 `/` 唤起块菜单，支持关键词过滤与键盘导航
- **悬浮工具栏**：选中文本浮现，加粗/斜体/删除线/行内代码/标题转换/链接/列表/引用/清除格式，`⋯` 可展开更多工具
- **块拖拽手柄**：悬停左侧出现，拖动排序、点击打开块菜单（类型转换 / 上移下移 / 删除）
- **表格**：斜杠插入 3×3 表格，光标进入后浮出操作条——加行 / 加列 / 删行 / 删列 / 删表格 / 单元格左中右对齐；编辑区带辅助线，**预览为隐形排版网格**（正式简历不出现表格线）

### 预览与导出

- **A4 纸张化预览**：794×1123px（96dpi），分页虚线与 PDF 切割位置一致；点击预览块可反向定位编辑器
- **智能一页**：内容超一页时自动等比缩放至恰好一页（顶栏可开关；内容过长触及下限时仍按多页处理）
- **PDF 导出**：html2canvas + jsPDF，与预览所见一致，支持多页
- **Markdown 导入导出**：`.md` 单向进出，与编辑数据双向无损转换

### 模板与排版

- 八套模板：**简约**（无衬线黑白）/ **经典**（衬线传统）/ **现代**（深色侧栏双栏）/ **标准**（单栏高密度 · ATS 友好）/ **雅致**（翡翠绿强调）/ **清爽**（浅色双栏）/ **商务**（蓝色竖条节标题 · 国内主流）/ **胶囊**（顶部色带 · 居中胶囊节标题 · 国内 Markdown 风），切换只换样式不动内容
- **主题色**：顶栏「主题色」一键覆盖模板强调色（8 个预设），编辑器与预览即时同步，导出 PDF 颜色一致
- **新建选模板**：新建简历时可从模板快照网格中预览并选用任一模板（也可从空白开始），模板切换不动内容
- **模板实时面板**：编辑器顶栏「模板」打开实时预览网格——按当前简历内容与主题色渲染全部模板缩略，点击即切换
- 现代模板约定：文档中第一个 `---` 分割线之前的内容进入左侧栏
- **证件照**：预览中上传（自动压缩存本机）、**拖拽移动**、**右下角手柄缩放**，位置比例随简历保存
- 左右分栏比例可拖动调整并记忆

### AI 助手

选中内容后触发，五种模式（顶栏「AI 助手」下拉或悬浮工具栏快捷模式）：

| 模式 | 说明 |
|---|---|
| 润色 | 更专业的表达，结构与原意不变 |
| 优化 | 强化量化成果、修正语病，条目可增删合并 |
| 精简 | 压缩篇幅至 50%~70%，保留关键信息 |
| 排版 | 规范标题层级与条目格式，重点前置 |
| 提问 / 要求 | 输入任意指令（如"翻译成英文""改写成 STAR 结构"） |

- **结构保真**：选区自动对齐到完整顶层块、以 Markdown 序列化送入模型，返回按块对齐替换——列表 / 标题 / 表格格式在润色前后保持一致
- **流式输出**：SSE 实时显示生成内容；语法检查显示已接收字数。超时语义为"无新内容才超时"（首字节 45s / 空闲 120s），长文生成不再受总时长限制
- **语法检查**：AI 通读整份简历，逐条给出错别字 / 语病 / 表达建议（附理由），确认后应用

**AI 配置**：设置 → AI 模型，填入 OpenAI 兼容的 Base URL（如 `https://api.xxx.com/v1`）、API Key 与模型名，可用「测试连接」验证。API Key 仅保存在本机浏览器。

### 数据与隐私

- 数据存储于浏览器 IndexedDB（库名 `ink-resume`），简历内容为 Tiptap JSON（旧版 Markdown 自动迁移）
- 设置 → 数据备份：一键导出/导入全量 JSON（简历 + 设置），可跨设备迁移
- 深浅色主题；预览纸张永远白底（打印媒介），导出不受工作区主题影响

## 架构要点

- **单一数据源**：编辑器与预览共享同一份 Tiptap JSON，顶层块通过 `data-index` 一一对应，预览点击可定位编辑器
- **模板即样式**：切换模板只更换 CSS 类，内容模型不动；现代模板以首个分割线拆分侧栏/主栏
- **AI 结构保真**：选区 → 顶层块对齐 → Markdown 序列化 → 模型 → 块对齐替换，规避"拍平文本丢格式"问题
- **智能一页**：隐藏测量分身（固定纸宽）取内容自然高度，与显示层解耦，避免"缩放↔重排"反馈循环

## 部署

`npm run build` 产物为 `dist/`，`vite.config.ts` 已配置相对路径（`base: './'`）与手动分包，可直接部署到任意静态目录、对象存储或 GitHub Pages 子路径。AI 功能依赖浏览器直连所选网关（需网关允许跨域）。
